👨‍💻 О проекте
Этот репозиторий содержит Python-приложение с графическим интерфейсом (на базе PyQt5) для прошивки и программирования embedded-устройств, таких как FPGA (Xilinx) и микроконтроллеры (STM32). Программа поддерживает несколько режимов прошивки через разные интерфейсы и инструменты. Она предназначена для упрощения процесса загрузки firmware на кастомные платы, включающие FPGA и MCU.
Приложение имеет тёмную тему, логирование операций, прогресс-бары и встроенную документацию. Основной файл запуска — main.py.

Возможности

BLCL Loader: Прошивка через серийный порт (COM) с использованием кастомного протокола BLCL. Поддержка загрузки bitstream для FPGA (.bit) и firmware для MCU (.bin). Автоматическое добавление CRC, генерация конфигурационного файла (config_file.bin), выбор режима (FPGA или MCU).
STM32 ST-Link: Прошивка STM32-микроконтроллеров через ST-Link с использованием STM32CubeProgrammer CLI. Поддержка .bin и .hex файлов, верификация и сброс.
Xilinx JTAG: Прошивка Xilinx Configuration Memory (.mcs) через JTAG с использованием Vivado или XSDB CLI. Поддержка очистки, верификации и прогресса на основе логов.
J-Link Flash: Прошивка MCU через J-Link с использованием JLink.exe. Поддержка разблокировки flash, выбор контроллера, сохранение настроек в JSON.
Дополнительно:
Чтение/установка версии и даты прошивки через COM (команды VER?, DATE?, SET_VER, SET_DATE).
Встроенная инструкция и ссылки на скачивание необходимого ПО.
Логирование с опцией детального вывода и сохранения в TXT.
Автоматический поиск CLI-инструментов на дисках.


Описание протокола BLCL (базовое)
BLCL (Bootloader Communication Layer) — это простой серийный протокол для общения с bootloader'ом на устройстве (FPGA или MCU). Он используется для загрузки данных через COM-порт (baudrate по умолчанию 115200, без указания parity/stop-bits — предполагается стандартная настройка).
Формат пакетов

Запрос от хоста: Первый байт — код команды (cmd), за ним — payload (данные).
Ответ от устройства: 8 байт:
[0]: 0xAA (стартовый байт).
[2]: Статус (если бит 7 установлен — ошибка).
Остальные байты: резерв или payload (не всегда проверяется).


Основные команды

TryConnection (handshake): Код 0x7F (для FPGA) или 0x7E (для MCU). Без payload. Устройство отправляет пакет, хост эхом возвращает. Таймаут: 30 сек.
WriteAddress (0x01): Payload — 4 байта адреса (little-endian) + 4 байта размера (little-endian).
WriteData (0x03): Payload — чанк данных (до 1024 байт).

Процесс прошивки

Handshake (TryConnection).
Для каждого файла: WriteAddress, затем чанки WriteData.
Финальный handshake и проверка строки "Start User App \r\n" в ответе (до 32 байт).
Буферы очищаются перед операциями. Ошибки: неверный размер ответа, отсутствие 0xAA, статус с ошибкой.

Протокол реализован в core/blcl_protocol.py с использованием threading для UI (сигналы log, progress, finished). Нет шифрования или сложной аутентификации — фокус на простоте.
Важные и ключевые моменты

Зависимости:
Python 3.x.
Библиотеки: PyQt5 (для GUI), pyserial (для COM), os/sys/time (стандартные).
Внешние инструменты (не включены, скачиваются отдельно):
SEGGER J-Link Software.
STM32CubeProgrammer.
Xilinx Tools (Vivado или Lab Edition).


Структура репозитория:
core/: Протоколы и flashing-логика (blcl_protocol.py, jlink_flash.py, stlink_flash.py, xilinx_flash.py).
firmware/: Примеры firmware (bootloader.hex, camera_app_L431.bin, fpga.mcs, test.hex).
logic/: Логические модули (logic_type1.py).
resources/: Ресурсы (icon.ico, documentation.md).
ui/: UI-компоненты (blcl_tab.py, stlink_tab.py, xilinx_tab.py, jlink_tab.py, version_tab.py, styles.py).
utils/: Утилиты (helpers.py — CRC, пакеты; markdown_formatter.py — Markdown в HTML).
main.py: Точка входа, сборка GUI.

Безопасность и ограничения: Нет поддержки сетевых протоколов или удалённого доступа. Таймауты: 10–60 сек в зависимости от вкладки. Ошибки логируются, но требуют ручной диагностики. Для MCU добавляется CRC (4 байта little-endian).
Разработка: Приложение асинхронно (QThread для flashing), с фокусом на удобство. Документация в resources/documentation.md (отображается в меню).
Запуск: python main.py. Убедитесь, что внешние CLI в PATH или указаны вручную.
Потенциальные проблемы: Если COM не подключается — проверьте драйверы. Для JTAG/J-Link — убивайте процессы (hw_server.exe) при ошибках. Программа ищет CLI на дисках C:/D:/E:.

Установка и запуск

Клонируйте репозиторий: git clone https://github.com/mrCtik/Programmer.git.
Установите зависимости: pip install pyqt5 pyserial.
Скачайте и установите внешние инструменты (см. меню "О программе" → "Скачивания").
Запустите: python main.py.
